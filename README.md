# API Automation Project

## 📌 Project Overview
This repository contains an **API Automation Framework** designed for testing REST APIs using industry-standard tools and best practices.  
The framework supports automated execution, detailed reporting, and easy integration with CI/CD pipelines.

---

## 🛠 Tech Stack
- **Programming Language:** Java 11
- **Build Tool:** Maven
- **Automation Framework:** REST Assured
- **Testing Framework:** TestNG / JUnit
- **JSON Processing:** Jackson
- **API Documentation:** Swagger (if applicable)
- **Reporting:** HTML Cucumber Reports
- **Version Control:** Git
- **CI/CD:** Jenkins / GitHub Actions (optional)

---

## ✅ Features
- Automated API test execution
- Support for GET, POST, PUT, DELETE requests
- Request & response validation
- JSON payload handling
- Configurable environments
- Reusable utility methods
- Test execution through Maven
- Detailed HTML reports
